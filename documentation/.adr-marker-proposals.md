## How to apply a marker

1. Open the file at the proposed line.
2. Insert `// AD-N: <Title>` as a comment (Dart `//` or JS `//` syntax matches both Flutter app and Worker).
3. In the same commit, delete the corresponding row from this file.
4. When the last row is removed, delete this entire file.

A stale row (marker already applied but row not deleted) is a `doc-enforce-lanes` MEDIUM `adr-marker-sidecar-stale` finding. An empty table is HIGH `adr-marker-sidecar-empty` and auto-deletes on the next `doc-updater` pass.
